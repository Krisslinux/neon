# Neon Hub

Neon-green Android home screen widgets: combined hub, AI launcher, battery, Bluetooth, and music. Built as a native Android app using Kotlin and Jetpack Glance.

## Build an installable APK on Codemagic

1. Connect this GitHub repository at https://codemagic.io/start/.
2. Select the **Neon Hub - Installable APK** YAML workflow from `codemagic.yaml` on `main`.
3. Start a build and download `app-debug.apk` from **Artifacts** after a successful build.

A debug APK is intended for personal testing. Android may require permission to install APKs from your browser/files app.
